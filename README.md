# 微信 AI 接入助手 / wechat-ai-bridge

面向非技术用户的 Windows 本地微信 AI 快速接入工具，基于 nexu 二次开发。核心价值是帮用户准备和管理运行环境，用自己的 API 快速连接微信；收费对象是软件或安装协助。

目标流程：安装并准备环境 → 填写用户自己的 API 并测试 → 微信扫码授权 → 查看连接状态，开始使用。

连接后提供可选的聊天建议和示例消息复制按钮，用户可以随时去微信试聊。首次回复不是完成配置或使用其他功能的前置条件；消息记录用于了解运行情况和排查问题。

「模型连接」在填写密钥并离开输入框后，自动读取服务商的模型列表（自定义接口需同时填写基础地址）。从下拉框选择模型后，再测试并保存；读取列表本身不会生成回答、保存配置或切换正在使用的模型。支持刷新及手动填写，列表以服务商返回内容为准，不保证其中每个模型都支持聊天。更换服务商会清空待提交的密钥，更换密钥或地址会清空旧列表。

支持 DeepSeek、阿里云百炼（北京）、硅基流动（中国大陆）的快捷地址，以及手动填写兼容接口。模型列表只属于当前 API；如果服务商返回能力信息，会展示名称、上下文和输出上限。当前模型未出现在完整的新列表时给出提示，不自动删除配置。

模型页的「高级设置」默认收起，可设置思考模式、请求时限（默认 90 秒）和网络重试（默认 1 次，最多 2 次）。思考控制目前仅验证 DeepSeek 官方 `deepseek-flash` / `deepseek-v4-pro` 的参数格式，其他模型保留服务商默认；不表示已经使用真实付费 API 完成验收。设置按 API 和模型保存，测试通过后同时用于微信运行时。时限覆盖单次模型调用及其网络重试；已开始返回内容的请求不会由传输层重发。首次配置仍只需填 API、选择模型并连接微信。

已有 API 时优先显示「已保存 API」，直接复用本机密钥读取列表、测试并切换模型，无需再次填写，也不把密钥回传到界面。需要更新密钥或添加接口时，点击「更换密钥或配置其他 API」。目前复用入口支持使用普通 API Key、无额外自定义请求头的 OpenAI Chat Completions 兼容配置；其他协议仍使用高级管理。

切换模型不会主动新开对话或删除已存历史，预设和联系人记忆也保留；运行时仍可能按上下文容量压缩历史。保存后后台重新连接，正在生成的回复可能中断，建议等该条回复结束再切换。新模型测试失败则保持原模型。

## 当前状态

交付方式确定为 Windows 压缩包：完整解压后运行 EXE，无需安装开发环境。当前不做代码签名、安装器或自动更新；诊断日志改造和操作系统密钥加密暂缓。首版验证重点是解压运行、微信收发、重启后配置保留和常见故障恢复。

已完成第一轮功能精简和首次配置流程改造：默认 DeepSeek，填写 API 后实际生成测试回答，再保存并选择模型；提供有限重试的微信扫码、运行状态、回复阶段记录、暂停／恢复、用户预设和新开对话。2026-10-21 已在本机 Windows 解压版验证一次真实微信收消息、模型生成和手机收到正常回复，见 [收发检查记录](docs/project/WECHAT-REPLY-CHECK-20261021.md)。异常恢复、安装器验收和密钥存储改造尚未完成，当前代码不是已验收的收费产品。

本仓库为独立的公开开发仓库，保留上游 MIT 许可。源码基线和差异见 [UPSTREAM.md](UPSTREAM.md)。

## 产品边界

- 用户自行购买和管理模型 API；不提供模型额度、云端托管或聊天内容服务。
- 程序在用户自己的 Windows 电脑上运行；电脑需要开机、联网且未休眠。
- 第一版仅做个人微信 ClawBot 接入，不承诺普通微信群或可被他人添加的普通微信账号。
- 用户自己编辑预设；提供新开对话与明确的数据清理入口。
- 默认关闭电脑命令执行、任意文件操作、浏览器控制、技能市场和自动任务。
- 模型配置接口只回传密钥已保存标记；更换模型复用本机密钥。操作系统密钥加密和诊断日志改造暂缓。
- 小程序和远程手机控制不在第一版范围内。

## 开始开发

开发依赖安装、类型检查以及前端、控制器和桌面壳构建已验证。本机已运行完整 OpenClaw 并验证一次真实微信收发，安装器、异常恢复和其他目标设备仍需单独验收。

开发机准备 Node.js 24 或以上及 pnpm 10.26.0（以 package.json 为准）。这些是开发依赖，不应要求最终用户安装。

```powershell
pnpm install
pnpm --filter @nexu/shared build
pnpm dev start
```

首次安装会执行上游 postinstall，准备运行时和依赖。开始前应先阅读 [AGENTS.md](AGENTS.md) 与 [开发计划](docs/project/ROADMAP.md)。

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm dev stop
pnpm dist:win:local
```

最后一个命令仅用于本地 Windows 打包检查，不代表发布版安装包已经验收。

Windows 打包前先停止开发服务，避免开发文件监视器占用暂存目录。如果 Electron 下载不可用，可把环境变量 `NEXU_DESKTOP_ELECTRON_DIST` 指向已安装、版本一致的 Electron `dist` 目录；不会自动下载或安装新版本。

打包会检查微信插件自己的生产依赖，不能依靠仓库根目录的依赖代替。若曾通过 `NEXU_SKIP_RUNTIME_POSTINSTALL` 跳过运行时准备，需先运行 `npm --prefix apps/controller/static/runtime-plugins/openclaw-weixin ci --omit=dev --ignore-scripts --no-audit --no-fund`，再重新打包。否则用户目录中的插件可能因缺少 `zod` 等模块而无法收消息，即使主界面和本地服务能够正常打开。

## 聊天行为设置

「聊天行为」管理实际收发节奏、表情图库、主动联系及联系人记忆。篇幅、结构、语气和是否追问由当前聊天决定；可以直接说“简单点”“展开讲讲”“别分点”，无需打开设置。这些聊天要求仅随当前上下文生效，不自动保存为跨对话偏好。完整用户预设仍在「回答风格」中编辑。

2026-10-23 已简化界面文案，并使用虚构情景进行了真实模型试聊，调整默认人设和接话提示。最终样本、剩余问题、测试边界及开发侧复测方法见 [聊天体验检查](docs/project/CHAT-EXPERIENCE-CHECK-20261023.md)。这不代表完整微信链路或真人满意度已经验收。

新配置默认使用社区灵感的「鲸鱼娘／大肥鱼」聊天风格，不随更换模型而消失：日常俏皮温暖，认真问题优先准确实用。在「回答风格」中可改成跟随 DeepSeek、关闭默认人设，或将模板载入编辑框后自行修改。自定义预设优先；清空自定义内容会恢复所选默认人设。升级保留已有明确选择。该预设是独立编写的社区风格模板，不代表 DeepSeek 官方身份。首次使用仍只需填写 API、连接微信，无需先调整人设或聊天行为。

首次配置和 DeepSeek 模型默认显示「大肥鱼蓝」主题，使用社区鲸鱼娘透明立绘与眨眼素材，辅以漂浮和气泡动效。「配色」中可关闭跟随模型、手动选择五种配色；动效开关和系统减少动态效果设置均生效。主题与聊天人设独立配置，不开启图库发送或主动聊天。

鲸鱼娘图片作者：[YunYueSama](https://github.com/YunYueSama/codex-deepseek-pet)，仓库：<https://github.com/YunYueSama/codex-deepseek-pet>。使用原始 `assets/whale/idle-front.png`，未修改图片，仅由 CSS 选帧和浮动。完整署名许可与第三方权利边界见 [第三方声明](THIRD_PARTY_NOTICES.md)；应用「使用说明」也提供署名及许可入口。该许可开放作者有权授权的贡献，不等于底层角色已完成商用权利核查。

- **表情图库**：导入自己的 PNG / JPEG / GIF 图片，每张不超过 2 MB，最多 24 张。填写名称和适用场景标签，开启后模型按语境选择，程序按概率和同一会话冷却间隔控制，一次最多一张。图片通过微信图片消息发送；不承诺原生收藏表情或 GIF 动画效果。图库只存本机，发送时上传微信；模型只接收名称与标签。
- **主动聊天**：默认关闭。选择微信连接，设置安静间隔、免打扰时段、每个会话每日尝试上限、连续未回复上限和话题提示。仅向所选连接中通过授权且在本次启动后发过消息的会话尝试发送；首页暂停也会暂停主动聊天。使用本机时区，需要电脑和软件持续运行，会消耗用户 API 用量。
- 主动调度复用正常模型与微信链路，不开启通用 OpenClaw cron、系统命令或任意文件工具。每天的尝试计数持久化；发送失败停止该会话的主动尝试，收到新消息后再恢复。重启后先在微信发一条消息以获得当前会话凭据；程序对超过 24 小时的本地缓存凭据不尝试发送，这不是微信承诺的有效期，服务端可能更早拒绝。
- 运行记录区分普通回复与主动触发。微信接受发送不等于手机收到或已读；主动消息和表情图片仍需在目标 Windows 打包版本做真实微信验收。

Windows 窗口默认固定为 1280 × 800，屏幕可用区域较小时自动缩小；可以移动和最小化，不允许拖动边框缩放或最大化。主要功能分独立页面，常见桌面窗口中完整显示；小窗口和展开的长内容保留滚动。

连接后可以直接在微信聊天，不用进入设置选择倾诉、闲聊或求助模式。每次回复由用户配置的模型结合当前消息和上下文接话；从吐槽转到求助、再转到玩笑，也按当下表达理解。规则随每次请求自动加载，从未保存聊天行为设置也生效；旧版本生成的固定模式、篇幅和表达指令在运行时自动忽略，无需重新保存。

「聊天行为」默认打开「接话与节奏」，保留等候连续消息、整段／分条发送及分条停顿等程序控制。旧的聊天方式链接仍可打开此页。自动提取长期记忆仍关闭。

短句分条由实际发送程序执行，新配置默认最多拆成 2 条，间隔 1.2 秒；可改回整段发送或调整到最多 3 条、间隔 0.5–3 秒，升级保留已保存设置。仅拆分不超过 360 字符的简短散文，按中文句末标点、问号、感叹号或换行保留句子；长回答、代码、列表、引语与链接保持完整。分条不额外请求模型。

「等你说完再回复」新配置默认自动接话：带句末标点或较长文字先等 2.5 秒，普通短句等 4 秒，逗号等未完结标点等 7 秒；连续补充时参考最近发送间隔，单次等待不超过 7 秒，每批最多合并等待 20 秒。这是本机节奏规则，不能判断真正的语义完整性，也无法感知微信正在打字；不是经真实试聊测定的最佳时长。无需额外模型请求。升级保留旧的固定等待设置（含 0 秒立即处理），也可切换自动接话；固定模式每批仍最多等待 90 秒。两种模式均最多合并 20 条或约 12,000 字符，图片、引用、命令与不同会话不混合。上述等待之后还需排队和模型生成时间，同一连接依次处理，生成期间新消息继续排队。等待队列只在内存中，暂停或退出会放弃尚未发送的内容，不在恢复后补发。

自动接话指导强调回应具体内容、倾诉时先听、明确求助时给出有用的下一步；同一句话兼有情绪与求助时兼顾，不固定重复安慰、强行升华或要求用户继续聊天。意思不明确时自然接话，仅在确实影响回答时澄清，不反复要求用户选择倾听或建议。收到一组分条消息时，整体理解并优先采用后续纠正。主动问候避免定时打卡式重复、责怪未回复与索取关心。这些属于模型表达指导，需用真实对话评估效果。

「聊天行为 → 联系人记忆」按实际通过授权的微信会话列出联系人，不读取手机通讯录。可分别设置本机备注、称呼、相处方式、聊天习惯，以及最多 20 条自己编写的记忆；记忆默认不使用，明确启用后只随该联系人的请求发送给用户配置的模型。本机备注不发送给模型。清空记忆会关闭使用并阻止仍在生成的旧配置回复继续发送，但不删除聊天记录、微信或服务商保存的数据；需要清除当前上下文时另用「新开对话」。

主动聊天可选择延续最近话题或轻松问候，并对单个联系人关闭或覆盖话题模式。最近话题只暂存在本次运行的内存中；收到新消息后取消尚未发送的主动回复，再按新消息处理。对“晚安”“别打扰”等明确关键词暂缓主动联系，直到对方再发消息；这是保守关键词规则，不代表模型可靠理解所有休息意图。所有联系人仍受全局开关、免打扰和次数上限约束。

升级说明：会话现在按微信账号、渠道与联系人隔离。原来按联系人共享的上下文不会自动迁移，升级后下一条消息开始新的隔离上下文，旧的本机记录保留。

本地备注修改不再中断生成中的回答；称呼、实际使用的记忆或聊天习惯变化仍会停止旧回复，运行记录显示「已停止」。清空记忆单独使旧回复失效，即使之后恢复相同内容也不会重新放行。文字已成功发送、可选表情失败时保留成功状态，额外提示表情未发出；只有图片的回复发送失败仍按失败处理。

暂停会忽略新收到的消息，不在恢复后补发；发送前及分条之间检查暂停，已提交微信的请求无法撤回。暂停、服务退出或分条发送失败会停止余下分条。新开对话通过运行服务重置上下文，保留预设和历史本机记录。「运行记录」显示最近消息处理状态，其中的发送确认表示微信接口接受了请求，不代表手机已读，也不要求用户确认后才能继续使用。
