# 微信 AI 接入助手 / wechat-ai-bridge

面向非技术用户的 Windows 本地微信 AI 快速接入工具，基于 nexu 二次开发。核心价值是帮用户准备和管理运行环境，用自己的 API 快速连接微信；收费对象是软件或安装协助。

目标流程：安装并准备环境 → 填写用户自己的 API 并测试 → 微信扫码授权 → 查看连接状态，开始使用。

连接后提供可选的聊天建议和示例消息复制按钮，用户可以随时去微信试聊。首次回复不是完成配置或使用其他功能的前置条件；消息记录用于了解运行情况和排查问题。

## 当前状态

已完成第一轮功能精简和首次配置流程改造：默认 DeepSeek，填写 API 后实际生成测试回答，再保存并选择模型；提供有限重试的微信扫码、运行状态、回复阶段记录、暂停／恢复、用户预设和新开对话。2026-10-21 已在本机 Windows 解压版验证一次真实微信收消息、模型生成和手机收到正常回复，见 [收发检查记录](docs/project/WECHAT-REPLY-CHECK-20261021.md)。异常恢复、安装器验收和密钥存储改造尚未完成，当前代码不是已验收的收费产品。

本仓库为独立的公开开发仓库，保留上游 MIT 许可。源码基线和差异见 [UPSTREAM.md](UPSTREAM.md)。

## 产品边界

- 用户自行购买和管理模型 API；不提供模型额度、云端托管或聊天内容服务。
- 程序在用户自己的 Windows 电脑上运行；电脑需要开机、联网且未休眠。
- 第一版仅做个人微信 ClawBot 接入，不承诺普通微信群或可被他人添加的普通微信账号。
- 用户自己编辑预设；提供新开对话与明确的数据清理入口。
- 默认关闭电脑命令执行、任意文件操作、浏览器控制、技能市场和自动任务。
- API 和聊天数据的存储保护、日志脱敏及隐私边界必须在发布前完成。
- 小程序和远程手机控制不在第一版范围内。

## 开始开发

开发依赖安装、类型检查以及前端、控制器和桌面壳构建已验证。本机已运行完整 OpenClaw 并验证一次真实微信收发，安装器、异常恢复和其他目标设备仍需单独验收。

开发机准备 Node.js 24 或以上及 pnpm 10.26.0（以 package.json 为准）。这些是开发依赖，不应要求最终用户安装。

```powershell
pnpm install
pnpm --filter @nexu/shared build
pnpm dev start
```

首次安装会执行上游 postinstall，准备运行时和依赖。开始前应先阅读 [AGENTS.md](AGENTS.md) 与 [开发计划](docs/project/ROADMAP.md)。

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm dev stop
pnpm dist:win:local
```

最后一个命令仅用于本地 Windows 打包检查，不代表发布版安装包已经验收。

Windows 打包前先停止开发服务，避免开发文件监视器占用暂存目录。如果 Electron 下载不可用，可把环境变量 `NEXU_DESKTOP_ELECTRON_DIST` 指向已安装、版本一致的 Electron `dist` 目录；不会自动下载或安装新版本。

打包会检查微信插件自己的生产依赖，不能依靠仓库根目录的依赖代替。若曾通过 `NEXU_SKIP_RUNTIME_POSTINSTALL` 跳过运行时准备，需先运行 `npm --prefix apps/controller/static/runtime-plugins/openclaw-weixin ci --omit=dev --ignore-scripts --no-audit --no-fund`，再重新打包。否则用户目录中的插件可能因缺少 `zod` 等模块而无法收消息，即使主界面和本地服务能够正常打开。

## 目录

- apps/desktop：Electron 桌面外壳、后台生命周期和更新。
- apps/web：配置界面与微信扫码入口。
- apps/controller：本地配置、模型服务和运行时管理。
- packages/shared：共享数据结构与模型供应商配置。
- docs/project：本项目范围、阶段计划和验收标准。
- upstream-reference：上游文档、CODEOWNERS 和已停用工作流的归档。

内部 @nexu/* 包名暂时保留。模型切换所需的内部运行插件也继续保留。上游统计初始化和自动更新已停用。Windows 应用标识、产品名、注册表和默认数据路径已独立；图标、启动素材及帮助地址的完整替换仍待完成。

默认配置目录为 `~/.wechat-ai-bridge`，Windows 桌面数据默认位于 `%APPDATA%/wechat-ai-bridge`，不会自动导入原版 nexu 的配置。开发模式使用项目内的独立运行目录。

## 聊天行为设置

在「聊天行为」中配置语气、篇幅与文字 Emoji；完整用户预设仍在「回答风格」中编辑。偏好在下一次模型请求时加载，实际措辞由模型决定。

默认随 DeepSeek 使用社区灵感的「鲸鱼娘／大肥鱼」聊天风格：日常俏皮温暖，认真问题优先准确实用。在「回答风格」中可改成始终使用、关闭默认人设，或将模板载入编辑框后自行修改。自定义预设优先；清空自定义内容会恢复所选默认人设。该预设是独立编写的社区风格模板，不代表 DeepSeek 官方身份。

首次配置和 DeepSeek 模型默认显示「大肥鱼蓝」主题，使用社区鲸鱼娘透明立绘与眨眼素材，辅以漂浮和气泡动效。「配色」中可关闭跟随模型、手动选择五种配色；动效开关和系统减少动态效果设置均生效。主题与聊天人设独立配置，不开启图库发送或主动聊天。

鲸鱼娘图片作者：[YunYueSama](https://github.com/YunYueSama/codex-deepseek-pet)，仓库：<https://github.com/YunYueSama/codex-deepseek-pet>。使用原始 `assets/whale/idle-front.png`，未修改图片，仅由 CSS 选帧和浮动。完整署名许可与第三方权利边界见 [第三方声明](THIRD_PARTY_NOTICES.md)；应用「使用说明」也提供署名及许可入口。该许可开放作者有权授权的贡献，不等于底层角色已完成商用权利核查。

- **表情图库**：导入自己的 PNG / JPEG / GIF 图片，每张不超过 2 MB，最多 24 张。填写名称和适用场景标签，开启后模型按语境选择，程序按概率和同一会话冷却间隔控制，一次最多一张。图片通过微信图片消息发送；不承诺原生收藏表情或 GIF 动画效果。图库只存本机，发送时上传微信；模型只接收名称与标签。
- **主动聊天**：默认关闭。选择微信连接，设置安静间隔、免打扰时段、每个会话每日尝试上限、连续未回复上限和话题提示。仅向所选连接中通过授权且在本次启动后发过消息的会话尝试发送；首页暂停也会暂停主动聊天。使用本机时区，需要电脑和软件持续运行，会消耗用户 API 用量。
- 主动调度复用正常模型与微信链路，不开启通用 OpenClaw cron、系统命令或任意文件工具。每天的尝试计数持久化；发送失败停止该会话的主动尝试，收到新消息后再恢复。重启后先在微信发一条消息以获得当前会话凭据；程序对超过 24 小时的本地缓存凭据不尝试发送，这不是微信承诺的有效期，服务端可能更早拒绝。
- 运行记录区分普通回复与主动触发。微信接受发送不等于手机收到或已读；主动消息和表情图片仍需在目标 Windows 打包版本做真实微信验收。

Windows 窗口默认固定为 1280 × 800，屏幕可用区域较小时自动缩小；可以移动和最小化，不允许拖动边框缩放或最大化。主要功能分独立页面，常见桌面窗口中完整显示；小窗口和展开的长内容保留滚动。

在「聊天行为 → 聊天方式」中可一键选择自然朋友、温柔陪伴或利落助手，再保存。方案组合语气、篇幅、追问频率与发送节奏；保留自己的完整预设和对话示例，不自动开启主动聊天或表情发送。默认表达指导减少客服套话、重复问候、强行建议与每句结尾追问，按当前问题复杂度展开。

「接话与节奏」可设置少追问／自然接话／更好奇、是否使用括号动作，或填写自己的对话示例。示例作为表达指导随请求发送给用户配置的模型，适用于所有会话，不作为共同记忆；不要填某个联系人的私密资料。上下文仍沿用当前对话，不额外开启自动长期记忆。

短句分条由实际发送程序执行，每段最多拆成 2–3 条，间隔 0.5–3 秒；默认整段发送，自然朋友与温柔陪伴方案开启分条。仅拆分不超过 360 字符的简短散文，按中文句末标点、问号、感叹号或换行保留句子；长回答、代码、列表、引语与链接保持完整。分条不额外请求模型，不合并用户连续发来的多条消息。

暂停会忽略新收到的消息，不在恢复后补发；发送前及分条之间检查暂停，已提交微信的请求无法撤回。暂停、服务退出或分条发送失败会停止余下分条。新开对话通过运行服务重置上下文，保留预设和历史本机记录。「运行记录」显示最近消息处理状态，其中的发送确认表示微信接口接受了请求，不代表手机已读，也不要求用户确认后才能继续使用。
