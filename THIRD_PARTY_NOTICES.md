## Distribution gate

Before distributing an installer:

- Generate and review notices for the exact dependency versions in the built application.
- Audit bundled runtime plugins and third-party assets separately.
- Replace inherited branding with owned or authorized branding.
- Retain applicable copyright notices, license texts and required source offers.
- Confirm the installer includes these notices.

This file records the initial known upstream source; it is not a completed dependency-license inventory.
