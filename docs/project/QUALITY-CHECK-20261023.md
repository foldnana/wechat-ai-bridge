## 已确认并修复

1. **并发保存覆盖配置。** 原存储仅排队写文件，读取和修改在队列之外，两个并发更新可能丢失其中一个。现在整个读取、修改、校验、写入过程串行执行。此保证针对同一个存储实例，不是跨进程文件锁。
2. **磁盘写入失败后无法恢复。** 原 Promise 队列在一次拒绝后持续拒绝后续操作。现在当前调用仍得到错误，但下一次保存可以重试；修改失败也不会污染内存中的有效配置。
3. **配置损坏时静默重置。** 原配置和备份都不可读时会写入默认值。现在只有两个文件均不存在才初始化；有有效备份时恢复，否则报错并保留文件。
4. **模型已保存、后台未就绪时提示消失。** 新 API 保存后自动切换到已保存连接面板，原错误提示跟着表单卸载。现在提示保持可见，也不再展示“模型准备好了”的成功卡片。
5. **预设加载过程中可误点模板。** 预设读取、保存期间禁用“编辑大肥鱼预设”，避免与异步结果竞争。
6. **表情开启却没有图片时反馈不足。** 新增图库为空的说明；图库读取完成前禁用导入，避免用户误以为开关开启后就能直接发表情。

配置存储新增 5 项回归测试。修复前 4 项失败、1 项通过；修复后全部通过。模型保存后错误提示消失也已通过浏览器操作复现，再验证修复。
