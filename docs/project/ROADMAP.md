# 开发计划与验收标准

状态：第一轮功能精简和首次配置流程改造已完成代码实现，见 [精简记录](CLEANUP.md)。2026-10-21 已在本机 Windows 解压版完成一次真实微信收发；异常恢复、其他目标设备和 Windows 安装器验收尚未完成。

## 目标用户和交付

面向不懂服务器、命令行和运行环境的 Windows 用户，提供可销售的微信 AI 快速接入工具。核心交付是准备和管理所需环境、配置用户自己的 API、连接微信，减少安装和配置中的人工操作。收费对象是软件或安装协助，不销售模型额度、不托管用户机器人。

产品成功标准：用户能快速配好环境、API 和微信连接，看懂当前运行状态；日常故障有可操作的恢复提示。

配置完成依据环境、模型配置和微信连接状态，不依赖首条回复。最后可提供示例消息复制按钮，引导用户自愿去微信试聊；不要求发送、等待回复或勾选确认，也不以此限制其他功能。真实收发和异常恢复仍属于开发侧的质量验证，不做成用户的必过步骤。

## 第一版范围

主工作空间拆成七个独立页面：

1. 总览：连接进度、环境状态、自动回复开关和下一步入口。
2. 模型连接：服务商、密钥和模型测试；成功后直接前往微信授权。
3. 微信连接：扫码指引、授权、连接状态、重新连接和可选试聊建议。
4. 回答风格：用户自己编写的预设和表达偏好。
5. 对话管理：分页查看微信会话、新开对话。
6. 运行记录：每条连接最近一次消息处理阶段和错误恢复入口，分页展示。
7. 聊天行为：语气与篇幅偏好、用户导入的表情图库、显式启用的定向主动聊天。三个紧凑面板分别配置，默认不发图片、不主动发送。

软件级设置（开机启动、窗口关闭行为、更新、故障报告、开源许可）及显式本机数据清理仍按后续里程碑补齐。主要桌面页面以常见窗口无需纵向滚动为布局目标，小窗口保留自然滚动以保证内容可达。

排除：云端托管、模型转售、nexu 账号/积分/奖励、其他 IM 渠道、技能市场、办公自动化、小程序、普通微信群支持承诺。

头像修改不作为第一版承诺，须先核实微信通道是否允许程序化修改。新开对话、清除长期记忆、删除本机记录是不同操作；不宣称可以删除微信服务器或模型服务商保留的数据。
